# Hybrid Dynamic Parser

The `HybridDynamicParser` allows for dynamic syntax switching between Null-Lang English and Modern syntax on a per-statement or per-block basis. It supports three output modes: Auto, Semi-Auto, and Manual.

## Output Modes

### 1. Auto Mode
In Auto mode, the parser automatically detects the syntax for each statement or block using keyword markers.

Example:
```
SET x TO 42           # English detected
let y = x + 1;        # Modern detected
SHOW y                # English detected
```

### 2. Semi-Auto Mode
In Semi-Auto mode, users can provide hints via comments. The parser validates the hint against the detected mode.

Example:
```
# mode:modern
let z = 100;
# mode:english
ADD 5 AND z
```

### 3. Manual Mode
In Manual mode, explicit directives are used to set the syntax mode for subsequent statements.

Example:
```
@syntax:english
SET count TO 0
@syntax:modern
let result = count + 10;
@syntax:english
SHOW result
```

## Architecture

### Unified AST
All AST nodes now include a `syntax_mode` field which records whether the node was parsed as English or Modern syntax.

### Scope & Symbols
Scope and symbol tracking are unified across syntax boundaries. Variables defined in English are accessible in Modern syntax and vice versa.

### IR Metadata
The Super-Bit IR generated by the compiler includes `syntax_mode` metadata for each token, preserving the source syntax information throughout the compilation pipeline.

## Usage

```python
from null_system.lang import HybridDynamicParser, OutputMode

parser = HybridDynamicParser()
program = parser.parse(source, OutputMode.AUTO)
```
